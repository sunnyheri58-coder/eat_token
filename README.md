# EAT Token - Crypto Exchange Platform

एक modern token exchange platform जहां आप crypto tokens को खरीद और बेच सकते हैं।

## 🚀 Features

- 💰 Real-time token prices
- 👤 User authentication (Email & Google)
- 📊 Advanced trading dashboard
- 💳 Multiple payment options
- 📈 Price charts and analytics
- 🔒 Secure transactions
- 📱 Responsive design

## 🛠️ Technology Stack

### Frontend
- React 18
- Tailwind CSS
- Redux Toolkit
- Axios
- Chart.js

### Backend
- Node.js + Express
- MongoDB
- JWT Authentication
- Socket.io (Real-time updates)

### DevOps
- Docker
- GitHub Actions
- AWS/Vercel deployment

## 📦 Installation

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
# Update .env with your credentials
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
